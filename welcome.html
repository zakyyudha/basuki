Basuki · v3

Test APIs with less guesswork.

Basuki redirects requests, returns controlled mock responses, and opens isolated browser sessions for development workflows.

Redirect

Match plain text contained in a request URL and send it to another destination. Localhost destinations are relayed through Basuki.

Intercept

Return a controlled status and response body for matching URL text and HTTP methods. Use ALL to match every method.

Session

Launch isolated browser sessions with separate storage. Saved presets remain reusable after the popup closes.

Pause disables redirect and mock execution globally without changing each rule's Enabled setting. Open Basuki from your browser toolbar to create your first rule.
